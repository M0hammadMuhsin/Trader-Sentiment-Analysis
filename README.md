# Trader-Sentiment-Analysis
# Trader Performance vs Market Sentiment

## Overview
This project analyzes the relationship between Bitcoin market sentiment (Fear/Greed) and trader behavior on Hyperliquid.

## Objective
To identify behavioral patterns and performance differences across sentiment regimes and derive actionable trading strategies.

## Methodology
- Data cleaning and standardization
- Daily feature aggregation
- Sentiment alignment at the daily level
- Trader segmentation (exposure & clustering)
- Comparative analysis across sentiment regimes

## Key Findings
- High exposure traders dominate profitability across regimes.
- Greed periods generate the highest absolute returns.
- Distinct trader archetypes exhibit varying risk-return profiles.
